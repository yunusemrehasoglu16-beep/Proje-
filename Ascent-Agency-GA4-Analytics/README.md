# Ascent Agency | Digital Marketing & GA4 Analytics

## Project Overview

Ascent Agency is a conceptual digital marketing agency website developed as a practical project to combine digital marketing, website design, and web analytics.

The project was designed to simulate a real-world digital marketing environment where website performance and user interactions can be measured and analyzed using Google Analytics 4 (GA4).

## Website

**Live Website:** https://sites.google.com/view/ascentagency/ana-sayfa

## Objectives

* Build and publish a functional digital marketing agency website
* Apply digital marketing concepts in a practical environment
* Implement Google Analytics 4 for website measurement
* Track user interactions and engagement
* Understand user behavior through web analytics
* Develop a data-driven approach to digital marketing performance

## Tools & Technologies

* Google Sites
* Google Analytics 4 (GA4)
* Google Tag Manager (GTM)
* Web Analytics
* Digital Marketing

## GA4 Implementation

Google Analytics 4 was implemented to monitor website traffic, engagement, and user interactions.

Key events and interactions monitored include:

* Page views
* Scroll interactions
* Link and button clicks
* Call-to-action (CTA) interactions
* Form submissions

## Analytics Focus

The project focuses on understanding:

* How users interact with the website
* Which pages receive engagement
* How visitors navigate through the website
* Which interactions can be considered conversion-oriented
* How website data can support digital marketing decisions

## Skills Demonstrated

* Google Analytics 4
* Google Tag Manager
* Web Analytics
* Digital Marketing Analytics
* User Behavior Analysis
* Event Tracking
* Data Analysis
* Website Analytics

## Key Takeaway

This project provided practical experience in connecting a live website with analytics tools and translating user interactions into measurable data. It demonstrates how digital marketing activities can be supported by web analytics and data-driven decision-making.
